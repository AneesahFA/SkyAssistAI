# Customer Service Manual.pdf (Mock)

## Topics
- Complaint handling
- Escalations
- Accessibility support
- Special assistance
- Medical emergencies
- Compensation communication

## Guidance
Customer concerns should be acknowledged promptly and resolved where possible at first contact.
Issues requiring exceptions should be escalated to a supervisor with clear case notes.
Accessibility and medical-assistance requests must follow dedicated service procedures.

## Example Questions
- I want to file a complaint.
- I need wheelchair or medical assistance.
- Can this be escalated to a supervisor?

## Agent Response Pattern
1. Acknowledge concern and verify customer impact.
2. Resolve directly when policy allows.
3. Escalate with documented context when exceptions are needed.
