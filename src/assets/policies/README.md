# SkyAssist Mock Policy Documentation

This folder contains academic mock policy documents used as source references in the SkyAssist prototype.

Important:
- The current prototype answer engine uses keyword matching in `src/app/services/mock-ai.service.ts`.
- These files are documentation artifacts for demos and future integration.
- A production implementation would index these documents with Azure AI Search and retrieve grounded passages.

Documents in this folder correspond to source citations shown in the app.
